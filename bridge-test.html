2 · Block test (listen)

Schedules 16 sixteenth notes at 120 BPM, starting 0.5 s from now, all sent at once with timestamps. Then it freezes the page's main thread on purpose.

  1. Steady run of 16 notes: delivery is timestamp-driven and independent of the page.
  2. Silence, then a burst of notes at the end of the freeze: delivery waits for the main thread (JavaScript timers), so page work delays notes.
